Privacidad

Responsable: github.com/4404c. Contacto: expp.bel@gmail.com.

Qué se guarda en tu dispositivo

Tu progreso y un identificador anónimo generado al azar, en el almacenamiento del navegador.

Qué se guarda en el servidor

  • Un código derivado de ese identificador (hash) y tu apodo.
  • Tus mejores puntajes y los datos de esas partidas, para validar el ranking.
  • Los días en que jugaste, durante 90 días, y totales de uso: sesiones y partidas.

No pedimos nombre, email ni contraseña. Evitá usar tu nombre real como apodo: es visible para todos los jugadores.

Para qué

Para mostrar el ranking, evitar trampas y saber si el juego funciona. No vendemos estos datos.

Direcciones IP

El servidor usa tu dirección IP de forma temporal para limitar abusos y no la guarda en la base de datos del juego. La página se aloja en GitHub Pages, que también puede registrar tu dirección IP por seguridad.

Borrar tus datos

Escribinos al contacto de arriba para pedir que borremos tu apodo y tus puntajes.
